# Въпроси

Какво ще отпечата кода?

```c++
//1.
int a1 = 7 / 2;
std::cout << a1 << '\n';

//2.
char a2 = 'A';
std::cout << a2 << '\n';

//3.
int a3 = 5 % 3;
std::cout << a3 << '\n';

//4.
char a4 = 'A';
std::cout << a4 * a4 << '\n';

//5.
bool a5 = 11;
std::cout << a5 << '\n';

//6.
int a6 = 12;
std::cout << a6 * 0.4 << '\n';

//7.
double a7 = 5;
a7 += 12.2 + 13;
std::cout << a7 << '\n';

//8.
int a8 = 2 + 3 * 4;
std::cout << a8 << '\n';

//9.
int a9 = (2 + 3) * 4;
std::cout << a9 << '\n';

//10.
int a10 = 5;
std::cout << ++a10 << '\n';

//11.
int a11 = 5;
std::cout << a11++ << '\n';

 //12.
int a12 = 9 / 2;
a12++, ++a12;
std::cout << a12 << '\n';

//13.
double a13 = 9 / 10;
std::cout << a13 << '\n';

//14.
int a14 = 15 % 5;
std::cout << (a14 == false) << '\n';

//15.
bool a15 = 0;
std::cout << a15 << '\n';

//16.
int a16 = 7;
double b16 = 2;
std::cout << a16 / b16 << '\n';

//17.
int a17 = 5;
int b17 = 2;
std::cout << a17 / b17 * 2 << '\n';

//18.
int a18 = 4;
std::cout << a18++ + 2 << '\n';
std::cout << a18 << '\n';

//19.
int a19 = 4;
std::cout << ++a19 + 2 << '\n';
std::cout << a19 << '\n';

//20.
int a20 = 10;
int b20 = 3;
std::cout << a20 - b20 * 2 << '\n';

//21.
int a21 = 10;
int b21 = 3;
std::cout << (a21 - b21) * 2 << '\n';

//22.
int a22 = 5;
std::cout << (a22 > 3) << '\n';

//23.
int a23 = 5;
std::cout << (a23 < 3) << '\n';

//24.
int a24 = 0;
int b24 = 10;
std::cout << (a24 != 0 && ++b24 > 10) << '\n';
std::cout << b24 << '\n';

//25.
int a25 = 1;
int b25 = 5;
std::cout << (a25 == 1 || ++b25 > 5) << '\n';
std::cout << b25 << '\n';
```

# Задачи

! Имате право да използвате само знанията придобити от 1-вата лекция

### 1. Четност

Подава се целочислено число на конзолата. Отпечатайте 1, ако е нечетно и 0, ако е четно.

_Вход: 250, Изход: 0_

_Вход: 67, Изход: 1_

### 2. Обръщане

Подава се четирицифрено число на конзолата. Отпечайте те го наобратно

_Вход: 1234, Изход: 4321_

### 3. Азбука

От конзолата се чете латинска буква. Отпечатва се поредния и номер в азбуката, запетайка и след това 0, ако буквата е малка и 1 ако буквата е главна

_Вход: B, Изход: 2,1_
_Вход: z, Изход: 26,0_

### 4. Валутен курс

От конзолата се прочитат две числа с десетична запетая. Първото е сума в евро, а второто в американски долари. На конзолата да се изписва 1, ако двете суми са равни и 0, ако не са
Приемаме, че курсът евро към долар е фиксиран на 1.12

### 5. Калкулатор

От конзолата се прочитат две числа a и b. Ако a или b са невалидни (извън интервала [5, 93456]), да се изпише 1, ако са валидни да се напише 0. След това на следващия ред да се изчисли (a+b)^3 + (a-b)^2 - (a+b)^4.

### 6. Калкулатор 2.0

От конзолата се прочитат два реда от по три цифри (четени като символи). Да се превърнат в числа, след което да се сумират и да се отпечата на конзолата сумата им без последната цифра:

_Вход: 124 456, Изход: 58 // 124 + 456 = 580_

### 7. Хотел

В един хотел има 5 вида стаи, предназначени съответно за 1, 2, 5, 7 и 10 души.

От конзолата се въвежда едно цяло число (N) – броят на гостите, които трябва да бъдат настанени в хотела.

Напишете програма, която определя и извежда колко стаи от всеки вид трябва да бъдат използвани, така че всички гости да бъдат настанени, като общият брой на използваните стаи е минимален.

_Вход: 26_

_Изход:_

```
Rooms for 1: 1
Rooms for 2: 0
Rooms for 5: 1
Rooms for 7: 0
Rooms for 10: 2
```
